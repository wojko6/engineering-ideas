# Security policy

## Scope

This repository contains engineering concepts, architecture notes and test
plans. It is not the production implementation of ASUSWRT-Merlin, Tailscale,
Fedora, Android, Brave, OPNsense or other third-party projects mentioned here.

Security issues in those products should be reported to their respective
maintainers.

## Sensitive-data exposure in this repository

If you believe this repository accidentally exposes credentials, private keys,
real infrastructure identifiers, raw private evidence or other sensitive data,
**do not paste the sensitive value into a public issue**.

Contact the repository owner through the GitHub profile or use GitHub's private
security-reporting mechanism if it is available for this repository.

Include only the minimum information needed to identify the affected file and
revision.

## Public issue guidance

Public issues are appropriate for:

- broken links;
- documentation mistakes;
- architecture inconsistencies;
- reproducibility problems;
- incorrect or outdated public technical references.

Do not attach raw captures, private logs, configuration exports, credentials,
browser profiles or screenshots containing unrelated personal data.
