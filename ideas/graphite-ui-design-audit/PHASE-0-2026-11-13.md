## Proposed five-part visual direction

1. **Product:** a capable local KDE file manager with Finder-inspired interactions and familiar native behavior.
2. **Character:** calm, precise, ordered.
3. **Material:** neutral charcoal and restrained matte layers; not a generic glowing AI dashboard.
4. **Meaningful moments:** file content, icon semantics, operation progress, selection, and keyboard focus.
5. **Signature:** a consistent sidebar → file list → information pane depth hierarchy, including properties and dialogs.

A **synthetic, independent** offline HTML example contrasts historic violet values with a candidate graphite ramp: sidebar `#111315`, window `#17191B`, surface `#202326`, selection `#394046`, primary text `#EEF1F3`, secondary text `#BDC5CB`, focus `#DCE3E7`. The mockup contains no real filesystem data and makes no Qt compatibility claim. Static color contrast checks measured **15.54:1** for primary/window, **10.08:1** for secondary/window and **9.28:1** for primary/selected. These are only selected WCAG-style contrast ratios for candidate RGB pairs.
