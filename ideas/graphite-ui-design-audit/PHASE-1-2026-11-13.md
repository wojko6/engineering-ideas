## Small enhancement candidates (NOT YET PATCHED)

1. **Active-row legibility:** The current custom `SidebarDelegate` draws selected rows using white at alpha 34; hover uses white at alpha 14. Assess keyboard focus and selection with an actual selected sidebar entry before adjusting any values. Changes, if needed, should be limited to the custom delegate, preserving accessibility.
2. **Truncated long labels:** Observe existing hover tooltip behavior first. If missing, inspect the item model building in `rebuild()` in `FinderSidebar` and custom delegate `paint()` / `helpEvent()`; implement a tooltip only where it is genuinely needed. Prefer Qt's `ToolTipRole` when appropriate over invasive custom painting. Do not expose real user paths in public screenshots or logs.
3. **Active/inactive states:** Preserve existing `finderAccent()` usage unless a reproducible problem is observed. Do not weaken keyboard-focus indicators or drag/drop affordances to achieve neutrality.
